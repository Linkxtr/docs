## Release highlights (v0.1.0)

Version `v0.1.0` marks the initial open-source release of `linkxtr/filament-qr`.

### Features included

- **Filament Panel Plugin (`FilamentQrPlugin`)**: Clean registration via `$panel->plugin(FilamentQrPlugin::make())`.
- **Table Column (`QrCodeColumn`)**: Inline preview, responsive sizing, dark mode compatibility, click-to-download, and preview modals.
- **Infolist Entry (`QrCodeEntry`)**: High-contrast display with light-contrast backing and monospace payload readout.
- **Table Single Action (`DownloadQrAction`)**: Streaming download of individual QR codes in SVG, PNG, or WebP.
- **Table Bulk Action (`DownloadQrBulkAction`)**: Multi-record selection export into a compressed `.zip` archive.
- **Brand Colors & Token Support**: Native mapping for Filament palette tokens (`primary`, `danger`, `warning`, `success`, `info`, `gray`).
- **Advanced Aesthetics**: Linear gradient stops, per-eye corner color customization, and center logo embedding.
- **Payload Formatters**: Built-in helpers for Wi-Fi credentials (`asWifi`), URLs (`asUrl`), Emails (`asEmail`), and SMS (`asSms`).

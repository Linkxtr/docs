**Filament QR** (`linkxtr/filament-qr`) brings the high-performance QR code engine of [`linkxtr/laravel-qrcode`](https://github.com/Linkxtr/laravel-qrcode) directly into your Filament panels.

Whether you need inline scannable badges in table rows, high-contrast QR codes in resource infolists, or one-click exports, Filament QR provides a fluent, developer-friendly interface tailored for Filament v3, v4, and v5.

## Key features

- **Native Filament architecture**: Built as an official Filament plugin registered via `$panel->plugin(FilamentQrPlugin::make())`.
- **Zero layout shift**: Pure SVG rendering by default ensures crisp vectors at any display scale without external HTTP requests.
- **Theme integration**: Uses Filament color palette tokens (`primary`, `success`, `danger`, `warning`, `info`, `gray`) or standard HEX codes.
- **Advanced aesthetics**: Supports linear gradients, per-finder-eye color customization, and centered logo images.
- **Broad compatibility**: Tested across PHP 8.2 through 8.5, Laravel 11, 12, and 13, and Filament 3, 4, and 5.
